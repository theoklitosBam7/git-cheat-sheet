Reference v2.x

Git Cheat Sheet

Every command you actually need, organized for quick lookup

⚙
Setup & Config
git config --global user.name "Name"Set global username
git config --global user.email "e@mail"Set global email
git config --global core.editor vimSet default editor
git config --listList all config settings
git config --global alias.co checkoutCreate a command alias
git config --global color.ui autoEnable colored output
◈
Init & Clone
git initInitialize a new local repo
git init <directory>Init repo in specific folder
git clone <url>Clone a remote repository
git clone <url> <dir>Clone into named folder
git clone --depth 1 <url>Shallow clone (latest only)
git clone --branch <name> <url>Clone specific branch
◎
Staging
git statusShow working tree status
git add <file>Stage a specific file
git add .Stage all changes
git add -pInteractively stage hunks
git restore --staged <file>Unstage a file
git restore <file>Discard working dir changes
git rm <file>Remove file and stage deletion
git rm --cached <file>Untrack file, keep locally
●
Committing
git commit -m "message"Commit with inline message
git commit -am "message"Stage tracked files & commit
git commit --amendEdit last commit (msg or files)
git commit --amend --no-editAmend without changing message
git commit --allow-empty -m "msg"Create empty commit
git cherry-pick <hash>Apply commit from another branch
⌥
Branches
git branchList local branches
git branch -aList all branches (incl. remote)
git branch <name>Create a new branch
git checkout -b <name>Create and switch to branch
git switch <name>Switch to existing branch
git switch -c <name>Create and switch branch
git branch -d <name>Delete merged branch
git branch -D <name>Force delete branch
git branch -m <old> <new>Rename a branch
⌘
Merge & Rebase
git merge <branch>Merge branch into current
git merge --no-ff <branch>Merge with merge commit always
git merge --squash <branch>Squash all commits into one
git merge --abortAbort merge in progress
git rebase <branch>Rebase current onto branch
git rebase -i HEAD~NInteractive rebase last N commits
git rebase --continueContinue after conflict fix
git rebase --abortAbort rebase in progress
⇌
Remotes
git remote -vList remotes with URLs
git remote add origin <url>Add a remote
git remote remove originRemove a remote
git remote rename old newRename a remote
git fetchFetch all remotes
git fetch originFetch specific remote
git pullFetch and merge
git pull --rebaseFetch and rebase (cleaner)
git push origin <branch>Push branch to remote
git push -u origin <branch>Push and set upstream
git push --force-with-leaseSafe force push
git push origin --delete <branch>Delete remote branch
≡
Log & History
git logShow commit history
git log --onelineCondensed one-line log
git log --oneline --graph --allVisual branch graph
git log -pShow patches with commits
git log -n 5Show last 5 commits
git log --author="name"Filter by author
git log --since="2 weeks ago"Filter by date
git log --grep="keyword"Search commit messages
git show <hash>Show a specific commit
git shortlog -snCommits per author summary
±
Diff & Inspect
git diffUnstaged changes
git diff --stagedStaged vs last commit
git diff <branch1>..<branch2>Diff between two branches
git diff <hash>..<hash>Diff between two commits
git diff --statSummary of changed files
git blame <file>Who changed each line
git grep "pattern"Search working tree
git bisect startStart binary bug search
git bisect good <hash>Mark commit as good
git bisect badMark current as bad
⊙
Stash
git stashStash current changes
git stash push -m "msg"Stash with a description
git stash -uStash including untracked
git stash listList all stashes
git stash popApply & remove last stash
git stash apply stash@{N}Apply specific stash
git stash drop stash@{N}Delete a stash
git stash clearRemove all stashes
git stash show -pShow stash diff
↺
Undo & Reset
safe (creates new commits)
git revert <hash>New commit undoing a commit
git revert HEADRevert last commit
destructive (rewrites history)
git reset HEAD~1Undo commit, keep changes staged
git reset --soft HEAD~1Undo commit, keep changes staged
git reset --mixed HEAD~1Undo commit, unstage changes
git reset --hard HEAD~1Undo commit, delete changes
git reset --hard origin/mainReset to match remote
git clean -fdRemove untracked files & dirs
◈
Tags
git tagList all tags
git tag v1.0.0Create lightweight tag
git tag -a v1.0.0 -m "msg"Create annotated tag
git tag v1.0.0 <hash>Tag a specific commit
git push origin v1.0.0Push a tag to remote
git push origin --tagsPush all tags
git tag -d v1.0.0Delete local tag
git push origin --delete v1.0.0Delete remote tag
⟳
Reflog & Recovery
git reflogShow history of HEAD moves
git reflog <branch>Reflog for specific branch
git checkout <hash>Detach HEAD to any commit
git branch recovered <hash>Recreate branch from hash
git fsck --lost-foundFind dangling objects
git stash show -p stash@{0}Inspect a stash before applying
⊕
Submodules
git submodule add <url>Add a submodule
git submodule initInitialize submodules
git submodule updateFetch submodule commits
git submodule update --init --recursiveInit and update recursively
git clone --recurse-submodules <url>Clone with all submodules
git submodule foreach git pullPull in all submodules
✦
Advanced & Useful
git worktree add <dir> <branch>Checkout branch in new folder
git archive --format=zip HEADExport repo as zip
git bundle create repo.bundle --allBundle entire repo as file
git gcClean up & optimize repo
git count-objects -vHShow repo disk usage
git rev-parse HEADPrint current commit hash
git rev-parse --abbrev-ref HEADPrint current branch name
git ls-filesList tracked files
